Reported at the argument or input field, the detail naming what binds it: `PARAMETER` for a call parameter filled by its name, by its type or through an input object above it, `MEMBER` for a member of a class or record it is built into, `COMPARED` for a column a filter or a write compares or writes, and so on for a tenant, an `@outbox` key or a `@condition` taking it.

A generated scalar is a string on the wire, and inside the generated code its value is decoded into a record of components, `text`, `startType`, `path` and `endType` for a `SCHEMA_PATH` and `text` and `name` for a `TYPE_NAME`. The decode is where the value is checked against the schema the service serves, and where every `@assertType` on the argument runs. A call takes the components it needs by naming them in `argMapping`; any other binding would hand over the unchecked string, so it is refused rather than passed on.
