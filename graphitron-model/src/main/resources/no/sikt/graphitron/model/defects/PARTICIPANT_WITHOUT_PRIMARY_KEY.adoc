Reported at the field returning the interface or union, once for each participant on a table with no primary key.

A field returning an interface or union with no discriminator reads each participant from its own table and combines the reads into one. Every participant's rows are keyed by their table's primary key: the combined read orders by it and hands each row to its type by it. A row of a table with no primary key carries no such key. A node fetcher, a query field returning `Node`, and a `@service` read their rows otherwise, so neither is reported.

*Next step.* Give the table a primary key, or leave the type out of the interface or union. See xref:../how-to/polymorphic-types.adoc[How-to: Polymorphic types].
