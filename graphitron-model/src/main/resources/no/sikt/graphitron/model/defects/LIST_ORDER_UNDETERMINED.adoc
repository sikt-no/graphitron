A list or connection with no order to fall back on, for which no order is stated: no `@defaultOrder`, and no `@orderBy` argument a client must give. The order it falls back on is the primary key of the table its rows are read on; a table with no primary key, or a table-valued function's result, has none, and a function's result type is bound to no table unless its own `@table` binds it. An `@orderBy` argument a client may leave out states no default, since where it is left out the rows are read in the order the field falls back on. The list is read inside its parent's query, by a query of its own at the root or split from its parent, or as a `@routine`'s result, and over several types' tables each such table is reported. A lookup answers in its keys' order, and a `@service` or a write in the order it hands back, so neither is reported.
