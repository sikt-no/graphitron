Reported at the input field. Valid: `@nodeId(typeName:)` may name a union or interface whose members are nodes, and such an id is legal input.

An input object a call builds into a jOOQ record writes a node id's decoded key into the record's columns, which are one node's key. An id that may belong to any of several node types has no one set of columns to land in, and graphitron does not place it in a record yet.

*Instead.* Name one node type with `@nodeId(typeName:)`, or take the id outside the input object built into the record, as an argument or a parameter of its own. The xref:directives/service.adoc#constraints[`@service` constraints] list what an input object built into a record may hold.
