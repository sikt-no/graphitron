Reported at the code reference, the detail naming the class written in `className:`.

Graphitron reads the classes the build hands it before generating, so that every method it calls is checked against what is really there. A class that reading never met is either misspelt or lives in an artifact the module does not declare; this is told apart from a method that is missing on a class that was read, `CODE_REFERENCE_METHOD_NOT_FOUND`.
