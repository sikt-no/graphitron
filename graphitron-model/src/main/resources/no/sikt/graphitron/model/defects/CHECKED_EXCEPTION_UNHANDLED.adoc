Reported at the `@service` field, the detail naming the checked exception.

The generated fetcher calls the service inside a `try` that catches only what the field's errors channel claims. A checked exception nothing claims escapes the fetcher, which Java will not compile. `IOException` and `InterruptedException` are let through as infrastructure failures, redacted rather than surfaced.
