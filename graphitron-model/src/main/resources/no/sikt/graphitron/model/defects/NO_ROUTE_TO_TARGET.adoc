Reported at the element of the path's last step where a path is written, and at the field's declaration where none is, the detail then naming the two tables. Where the path ends on a `@routine`, it is reported at the `@routine`. A filter argument or input field whose column is on another table than the rows it filters, with no path to it, is reported at the argument or input field, the detail naming the two tables.

A field's rows come from the table its type is bound to, so its path has to arrive there. A written path whose every element was walked can still end on another table. An inferred one joins two tables over the one foreign key between them, and with none, or with both ends one table, there is nothing to infer. From a routine's result the join is on the target's primary-key columns matched by name, so a result lacking one of them has no route either. An argument of a root field returning an interface with a table of its own starts on the interface's table and lands on each member's, and no join is inferred for an argument.
