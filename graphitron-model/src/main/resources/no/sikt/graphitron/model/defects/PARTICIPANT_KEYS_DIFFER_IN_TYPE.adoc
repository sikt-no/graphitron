Reported at the field returning the interface or union, once for each participant whose table's primary key has a column of another type at some position than a participant before it by name, where the two keys have as many columns.

A field returning an interface or union with no discriminator reads each participant from its own table and combines the reads into one. Each read projects its table's primary key into the same columns, one column per key position, and the combined read holds one value of one type in each, so the reads line up only where every participant's key column at a position is exchanged with the database as the same type. That type is the one behind any converter: a `varchar(10)` and a `varchar(20)` key agree, as do a domain over `bigint` and a `bigint`, while an `integer` and a `varchar` key do not. Keys with different numbers of columns are reported as `PARTICIPANT_KEYS_DIFFER_IN_ARITY` instead. A node fetcher, a query field returning `Node`, and a `@service` read their rows otherwise, so neither is reported.
