Reported at the output field, the detail naming the Java class jOOQ binds the column to.

A generated scalar is a string on the wire. As output, a field of one reads its column and hands back the stored text as it is, without checking, since a stored value may predate a schema change. A column jOOQ binds to another class than `String`, a number, a date or a UUID, holds no such text.
