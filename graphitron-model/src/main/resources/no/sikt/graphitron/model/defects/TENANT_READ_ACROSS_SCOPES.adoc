Reported at the root field.

In a database-per-tenant build each tenant's rows live in that tenant's database, and the rows of a table no tenant column scopes live in the default one. A root field graphitron reads runs one statement on one connection. When the tables that statement reads include both kinds, as a union or interface whose members sit on a tenant's table and on a global one can, no connection holds them all. Naming the tenant does not help: the global rows are not in the tenant's database.
