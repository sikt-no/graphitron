Reported at the `facets` field's declaration, naming the connection type in the detail.

A connection's `facets` field and its facets type are generated by graphitron from the `@asFacet` fields of the connection's filter inputs, together with the code that counts them. A connection type you declare yourself does not gain one yet, so a `facets` field declared on it names a facets record nothing builds. A declaration standing in for a connection `@asConnection` generates is checked against the generated shape instead, by xref:#minted-type-declared-short[`MINTED_TYPE_DECLARED_SHORT`].

*Next step.* Remove the `facets` field, or let `@asConnection` generate the connection, with the filter's `@asFacet` fields giving it its facets.
