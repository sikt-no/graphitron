Reported at the field reading an interface or union, or at the type for a node or federation entity. Valid: a type whose fields read the session through a `@condition` may be a node, an entity or a participant of an interface or union, and is read the same way under a field returning it.

A `@condition` binding `$session` or `$session.<member>` on a field read into its parent's statement makes the parent type's projection take the statement's connection, and so every type projecting that one, through the fields read into its own statement. A field returning the type, and a `@service` lifting onto the type, hand the connection over. The node fetcher and the federation entity dispatch, which `Query.node` and `_entities` both read through, and the fetch of an interface or union whose participants are told apart by their tables or by a discriminator, select the type's projection without it, which graphitron does not generate yet.

*Instead.* Reach the type through a field returning it rather than through the interface, union, node or entity; read the session-reading field by a query of its own, with xref:directives/splitQuery.adoc[`@splitQuery`], so it no longer reads into the type's statement; or move the condition to a type these paths do not read. The xref:directives/condition.adoc[`@condition` reference] covers how a `$session` pair binds.
