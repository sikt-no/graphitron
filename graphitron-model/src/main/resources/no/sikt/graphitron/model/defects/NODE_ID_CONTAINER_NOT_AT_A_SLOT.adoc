Reported at the `@nodeId`, the detail naming the interface or union.

An id of an interface or union is decoded per member: the generated fetcher reads the id's type prefix and builds that member's own record, which only a Java slot typed as a record supertype can receive. Anywhere else the value binds a predicate or is encoded, and those need the key of one node type; an output field has nothing to encode from either.
