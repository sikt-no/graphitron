Reported at the field. Where a `@service` takes the keys, the detail names the parent's class.

Under a parent holding an object of a class rather than a table's row, a field that fetches its own rows takes their keys off that object: its own columns where it is a jOOQ record, otherwise a member of its class returning records of the table the field reads. A class with no such member hands over no key, so there is nothing to batch the fetch by.
