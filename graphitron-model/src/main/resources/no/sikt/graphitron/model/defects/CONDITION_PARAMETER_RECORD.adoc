Reported at the argument or input field bound to the parameter, the detail naming the jOOQ record class.

Building an input onto a jOOQ record's columns prepares a row to write, which is a `@service` feature. A condition only reads the input's values to build a predicate, so graphitron hands a `@condition` either the map graphql-java delivered or a bean built from it.
