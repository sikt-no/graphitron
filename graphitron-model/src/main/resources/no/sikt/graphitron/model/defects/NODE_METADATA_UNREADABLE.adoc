The table's generated class declares node metadata, `\\__NODE_TYPE_ID` and `\\__NODE_KEY_COLUMNS`, that graphitron cannot use, for example a type id without key columns. A node over the table then takes its identity from what the schema declares, else from the type's name and the table's primary key, which may not be the ids the class meant.
