Reported at the field, the detail naming the element's `name`.

On a plural mutation behind a routine, `@defaultOrder` orders the routine's own result, and reads nothing but its columns. A `path:` leaves for another table, so it names no column of the result. An element naming a `method:` is `SORT_KEY_METHOD`.
