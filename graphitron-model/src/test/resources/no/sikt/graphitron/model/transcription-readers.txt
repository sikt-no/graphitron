# Readings of graphql_type and graphql_field that have not been adjudicated against the expanded
# population. Frozen 2026-08-31, shrink-only.
#
# An entry here is not a claim that the reading is right. It is a claim that somebody knows it is
# there. The expansion used to write what it minted into these two relations, so every one of these
# readings got the expanded population for free and none of them chose it. Splitting the two made
# each one a decision, and this roster is the list of decisions still owed.
#
# A line leaves when its reading is adjudicated: repointed to graphitron_type or graphitron_field
# where the rule is about the schema the generator works against, or kept and moved under a reason
# heading below where the rule is genuinely about what an author wrote. A reading kept for a reason
# is still a reading of the transcription, so it stays on the roster with its reason beside it
# rather than disappearing from the count.
#
# The expanded population is two tables, filled by an insert-select over named set views: one view
# per set, and the authored set of each grain is a view over the transcription. So the population's
# own arms are entries here, under the reason heading at the foot of this file, rather than an
# exclusion. That the union is taken is still pinned where the rows are, in the capture agreement's
# emitted-element-family arm, rather than in any definition text.

# Adjudicated and kept: the authored arms of the emitted population.
#
# These two are the transcription by construction. graphitron_type and graphitron_field are each
# the union of an authored set and a minted set, and these are the authored sets. Repointing them
# at the anchors would define a relation in terms of itself, so there is no other population they
# could mean. They are readings chosen rather than inherited, which is what the roster asks, and
# they stay counted because a reading kept for a reason is still a reading of the transcription.
#
# The argument grain has an authored set too and is not here: its coordinate is spelled from
# graphql_argument, which was never a relation the expansion wrote into.

graphitron_field_authored graphql_field
graphitron_type_authored graphql_type

# Adjudicated and kept: the carrier the macro expansion expands.
#
# graphitron_connection_carrier reads graphql_field to ask what the author wrote at the carrier's
# coordinate, which is the whole of its admission test: @asConnection expands a bare list of a named
# type, and the list is the author's. Reading the emitted anchor would ask what the schema emits
# there, which after the rewrite is the connection this very relation is deciding to mint. That is
# the circularity as much as the wrong question, so the transcription is the population it means.
graphitron_connection_carrier graphql_field

# Adjudicated and kept: an entry defect reported at what an author wrote.
#
# graphitron_entry_defect_rule's COLUMN_UNRESOLVED and COLUMN_AMBIGUOUS judge a scalar field against
# the table its read arrives at and report at the field's own line, or at its @field. Both are the
# author's: a minted field has no line to report at, and none of the macro's minted fields is a
# scalar read off a column, so the expanded population would add rows they can only skip.
# CHAIN_WITHOUT_TARGET reaches a field's written path through the declaration
# graphql_field anchored, on the walk's terms below.
graphitron_entry_defect_rule graphql_field

# Adjudicated and kept: the tags the configuration applies.
#
# graphitron_configured_tag_rule reads graphql_field for the file each field was declared in, which is the
# whole of the configuration's rule: a <schemaInput tag> reaches what its matched files declare. A
# minted field was declared in no file and takes no configured tag, so the emitted anchor would ask a
# question the rule does not.
graphitron_configured_tag_rule graphql_field

# Adjudicated and kept: a type's backing follows the authored type graph.
#
# graphitron_type_backing_rule reads which type a field names, and which kind a type is, over the
# authored schema, as the closure it replaces did. A producer grounds an authored field's type, and a
# hop reads an authored field off its parent's class; a type the macro minted is grounded by no
# producer and offered by no member, so the expanded population would add rows nothing can back.
graphitron_type_backing_rule graphql_field
graphitron_type_backing_rule graphql_type

# Adjudicated and kept: a rewritten carrier takes the note of the file it was declared in. A
# <schemaInput descriptionNote> reaches what its matched files declare, and the carrier is a field a
# file declared before the expansion restated it.
graphitron_field_minted graphql_field

# Adjudicated and kept: a walk starts from a field's anchored declaration.
#
# graphitron_field_path_start_rule and graphitron_field_path_rule find where a field's walk starts
# and the element it takes next through the declaration graphql_field anchored, by its source
# position, so a field declared twice is walked once. Which declaration was anchored is a
# declaration site, which only the transcription states, and a field the macro minted wrote no path.
# graphitron_routine_result_rule reads where a field's path ends the same way, to name the function whose
# result the rows of the type it returns are.
graphitron_field_path_rule graphql_field
graphitron_field_path_start_rule graphql_field
graphitron_routine_result_rule graphql_field
