= Reference
:description: Authoritative descriptions of every directive, plugin parameter, and runtime API entry point.
:!toc:

Authoritative descriptions of every directive, every Maven plugin parameter, every runtime API entry point, and every diagnostic code Graphitron emits.

These pages are where Graphitron's rules are stated: what an author may write, what each directive means, what is refused and why, and what is generated. Tests verify the rules and encode them in code; the prose that explains them lives here. A change to a rule changes the page that states it in the same commit as its code and its tests, so a rule is never only in code.

== Runtime API

* xref:runtime-api.adoc[Runtime API reference]: the `Graphitron.buildSchema(...)` facade (single-arg and federation two-arg overloads), the `Graphitron.newExecutionInput(...)` schema-driven factory (`DSLContext` first, then typed `contextArgument` slots reflected from your `@service` / `@condition` directives), the sealed `GraphitronContext` per-request interface (`getDslContext`, `getContextArgument`, `getValidator`), the `NodeIdEncoder` utility (generic `encode`/`peekTypeId`/`decodeValues`/`decodeColumns` plus per-Node `encode<TypeName>` and `decode<TypeName>` helpers), and the consumer hooks a `GraphitronRuntime` carries (`FetcherErrorLog`, `FetcherErrorResponse`, `BatchSizeLimit`).

== Maven plugin

* xref:mojo-configuration.adoc[Maven plugin configuration]: every parameter on every goal of `graphitron-maven-plugin`. Covers the four goals (`generate`, `validate`, `capture`, `dev`), the shared `<configuration>` parameters (`outputDirectory`, `outputPackage`, `jooqPackage`, `schemaInputs`), the `dev`-only watch parameters (`port`, `debounceMs`, `skipInitial`), and the `<schemaInput>` POM binding.

== Editor support

* xref:lsp-requirements.adoc[LSP requirements]: the LSP's native runtime. Both the GraphQL grammar and the `libtree-sitter` runtime ship bundled, so there is no system dependency to install. Covers the supported host architectures and the startup diagnostics.
* xref:lsp-inlay-hints.adoc[LSP inlay hints and classification hover]: the three editor-side config keys (`graphitron.inlayHints.inferredDirectives`, `graphitron.inlayHints.classification`, `graphitron.hover.classification`) that surface Graphitron's inference and classification layers inside the editor. Default off; opt in per key.

== Diagnostics

* xref:diagnostics-glossary.adoc[Diagnostics glossary]: every closed-set diagnostic code the validator emits, organised by category. Covers the three top-level rejection kinds (`author-error`, `invalid-schema`, `deferred`), the nine name-lookup attempt kinds (`column`, `table`, `foreign-key`, `service-method`, `lifter-method`, `enum-constant`, `type-name`, `nodeid-key-column`, `dml-kind`), and the four deferred emit-block reasons.

== Federation

* xref:federation.adoc[Federation reference]: what a federation `@key` may select in a Graphitron subgraph, how its entities are resolved and when the node key is synthesised, and the four codes a key is refused with (`KEY_TYPE_NOT_TABLE_BOUND`, `KEY_ON_INTERFACE`, `KEY_SELECTS_NOTHING`, `KEY_FIELD_NOT_A_COLUMN`).

== Deprecations

* xref:deprecations.adoc[Deprecations]: aggregator for every deprecated directive argument, input field, and whole directive in the rewrite, with migration guidance pointing back at the canonical directive page.

== Directives

* xref:directives/index.adoc[Directive reference]: every directive in the rewrite's `directives.graphqls`, listed alphabetically and grouped by category. Each directive page carries its SDL signature, parameter table, canonical examples from the Sakila example schema, constraints, and cross-links to the recipes and explanation pages that frame it.
